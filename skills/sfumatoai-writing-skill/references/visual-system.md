## 1. 固定画布与排版

- 使用严格 3:4 竖版；推荐最终尺寸 1080×1440 或等比例更高分辨率。
- 封面大标题居中，主体词加粗放大，保持足够留白。
- 内页说明文字只放顶部或底部，不在画面中央悬浮。
- 仅在人物真实说话时使用气泡；气泡不得承担旁白。
- 中部优先用于人物、物体关系、动作和状态变化。
- 不添加 `2026`、`AI`、`YUAN`、关键词或其他四角角标。
- 标题和说明直接排在纯色背景上，不使用白色、米色、荧光色或彩色矩形文字底板。

## 2. 默认 A+ 画风

在用户没有为新项目指定其他风格时，使用已通过试跑的默认方向：

- 灰调长春花蓝纯色背景；
- 轻微暖纸张颗粒；
- 成熟复古编辑漫画与手绘故事感；
- 中等偏粗的炭黑轮廓；
- 低饱和青绿、橙、奶油和淡珊瑚配色；
- 适度封面对比度，但不引入幼态海报比例。

禁止渐变、霓虹、玻璃拟态、3D 科技图标、照片写实效果、密集 UI、伪文字、水印和无关品牌标识。

若用户提供新的风格参考，先做少量 A/B 校准，并把参考图分别标记为人物、风格、构图或情绪参考。不要复制参考图中的账号、日期、原文或专属版式。

## 3. 人物 IP 使用

- 把人物视为故事角色，而不是每页必须出现的装饰。
- 根据脚本决定无人、单人或多人；不要默认只能有一个人物。
- 保持发型、服装、标志性配件和整体气质等高识别特征。
- 允许视角、动作、表情和轻微面部比例变化，不追求僵硬的逐页复制。
- 不因“同脸”而牺牲故事表达、亲和力或既定画风。
- 人物不需要在画面正中央；中部应留给本页最重要的视觉关系。

仓库包含一组可选的作者品牌人物：成年东亚男性、短黑发、米色立领外套、白色 T 恤、宽松深色长裤和黑白运动鞋；行走状态可增加米白棒球帽、米色背包与黑猫挂件。它不是通用默认人物。仅在当前用户是权利人或已获明确授权时，按 [brand-ip.md](brand-ip.md) 使用三张参考图；其他用户应提供自己的授权人物素材。

## 4. 生成与文字分层

1. 先生成无字底图，预留顶部和底部文字安全区。
2. 在提示词中禁止可读文字、字母、数字、标签、伪文字、页码和角标。
3. 为每张图单独生成，不用一个提示词批量承担不同故事任务。
4. 使用确定性工具叠加关键中文，固定字体、字号、行距、位置和颜色。
5. 输出后逐字比对脚本，不接受图像模型自行拼写的中文。

推荐文件层次：

```text
topic/
├── raw/
├── text/
└── final/
```

## 5. 返修与版本控制

- 先查看目标图，再使用图像编辑能力。
- 一次只改一个问题，并重复声明全部不变量。
- 使用 `page-02-v2.png` 等版本化文件名，不覆盖已确认成图。
- 将原版与返修版并排展示，明确左/右或前/后。
- 用户拒绝返修后，把候选标记为未采用，不混入正式组。

## 6. 开源素材边界

- 不把来源不明的社交媒体图片、截图、人物参考或品牌素材直接提交到公开仓库。
- 仅公开自己拥有版权、获得明确授权或许可证允许再分发的素材。
- 对不能公开的参考图，仅保留文字化视觉规范，并在运行时要求用户自行提供。
- 发布仓库前检查每个图片、字体和示例文件的来源与许可。
- 区分代码许可与媒体许可；仓库内置品牌人物不属于 MIT，详见根目录 `ASSET_LICENSE.md`。
