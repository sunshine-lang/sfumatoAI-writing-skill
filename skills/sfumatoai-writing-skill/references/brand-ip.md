# 品牌人物 IP

仅当当前用户明确要求使用仓库作者的品牌人物，并确认自己是权利人或已获得书面授权时，读取并使用本规范。公开仓库可见不等于获得肖像或品牌使用许可。

## 权限门槛

- 权限明确：可把三张图片分别作为身份、姿态和构图参考。
- 权限不明确：不得把内置图片送入图像模型，也不得复刻人物面部；保留通用画风，并要求用户提供自己的授权人物参考。
- 只需要默认画风：不要加载人物图片，按 [visual-system.md](visual-system.md) 执行即可。

品牌图片受随附的 [assets/ip/LICENSE.txt](../assets/ip/LICENSE.txt) 单独约束，不属于 MIT License。

使用图像能力时明确标记输入角色，不要把三张图片都描述成编辑目标。

## 不变量

- 成年东亚男性；短黑发、直眉、椭圆脸、平静友好的轻微笑容。
- 米色立领外套、白色 T 恤、宽松深色长裤、黑白运动鞋。
- 行走状态可增加米白棒球帽、米色背包和黑猫挂件；站姿状态可不戴帽。
- 黑猫图形、黑白猫、笑脸、花朵和星形可作为辅助符号，但不要每页机械堆满。
- 保持成年比例，不幼化脸型、身高或肢体。

## 生成基线

生成全新画面，不直接擦除或覆盖旧图元素。以 `sfumato-ip-standing.png` 锁定人物身份，再按页面脚本选择行走版或侧脸版提供动作参考。延续长春花蓝、粗炭黑线条、暖纸张颗粒、低饱和米色、青绿、橙色与淡珊瑚色。

禁止生成可读文字、字母、数字、签名、角标、平台名称、水印或无关品牌。所有标牌使用箭头、花、星、笑脸或黑猫等纯图形，最终中文仍由确定性排版工具添加。
